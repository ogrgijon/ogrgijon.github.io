# When two files look the same, but are not

A number changes, a row appears, a column moves. In large Excel files, finding differences can become an exhausting manual search. Excel Comparador is a Python tool for comparing Excel files and making that review faster and more repeatable.

Making changes visible helps people review them in context and spend their time deciding what they mean, rather than tracing cells one by one.

## Less manual review, more time to act

When different spreadsheet versions arrive, finding changes manually takes time and makes it easy to miss something. This utility provides a straightforward starting point for file comparison and can be packaged for the target system with PyInstaller.

It may be especially useful where Excel is part of review and delivery processes. For reliability in a professional workflow, test it with real workbooks, agree how differences should be presented and validate edge cases such as formatting, sheets, formulas and expected data.

## Adaptable to existing processes

Useful for change control, delivery reviews or spreadsheet validation. The repository includes the starting point and basic instructions for setting up the environment and building the executable. Comparison behaviour and file formats should be validated against each organisation's real data.

## From a small utility to a concrete process improvement

Many valuable digital transformations start this way: a repeated task, a point of failure and a focused tool that brings clarity. The opportunity lies in adapting the comparison to what your team considers important and making the results easy to review and share.
