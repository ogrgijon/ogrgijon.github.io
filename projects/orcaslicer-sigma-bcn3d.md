# Give the BCN3D Sigma family a place in OrcaSlicer

This community project brings printer and print profiles for the BCN3D Sigma, Sigma R17, R18 and R19 to OrcaSlicer. It is intended to make it easier to configure these machines and get from a 3D model to a ready-to-slice project.

## Profiles for everyday print setups

The repository includes 0.4 mm nozzle configurations, print processes ranging from Extra Fine to Draft, and generic PLA, ABS and PETG filament profiles. Versioned profile folders make it possible to choose an edition and retain earlier configurations.

## Configuration files, not firmware

This project contains OrcaSlicer profiles only; it does not include or modify printer firmware and is not officially affiliated with or endorsed by BCN3D. Check that the selected profile matches your printer and setup, and validate settings before printing.
