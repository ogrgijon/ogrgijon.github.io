# La familia BCN3D Sigma, en OrcaSlicer

Este proyecto comunitario reúne perfiles de impresora e impresión para BCN3D Sigma, Sigma R17, R18 y R19 en OrcaSlicer. Su objetivo es facilitar la configuración de estas máquinas y el paso de un modelo 3D a un proyecto listo para laminar.

## Perfiles para configuraciones de impresión habituales

El repositorio incluye configuraciones para boquilla de 0,4 mm, perfiles de proceso desde Extra Fine hasta Draft y perfiles genéricos de filamento PLA, ABS y PETG. Las carpetas organizadas por versión permiten elegir una edición y conservar configuraciones anteriores.

## Configuraciones, no firmware

Este proyecto contiene únicamente perfiles para OrcaSlicer: no incluye ni modifica el firmware de la impresora y no está afiliado ni respaldado oficialmente por BCN3D. Comprueba que el perfil seleccionado corresponda a tu impresora y configuración, y valida los parámetros antes de imprimir.
