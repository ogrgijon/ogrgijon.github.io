# From physical movement to a clearer operation

In a warehouse, every location and movement is part of a larger operation. When processes and tools are disconnected, teams lose time piecing together what is happening. Merekai Warehouse explores a modular digital foundation to bring that experience together.

The project combines an Angular web client, a Fastify API and a Tauri desktop application. The API centralises business rules and persistence, while the interfaces share a common foundation.

## An architecture designed to evolve

Separating the interface, business rules and persistence is more than a technical choice: it makes the solution easier to evolve and opens the possibility of web and desktop experiences built on shared logic. The project uses SQLite for persistence and documents its structure and implemented features.

This architecture is a starting point. Integrations, scale, permissions and operational workflows should be defined with each organisation before considering production use.

## For organisations looking to organise their workflows

The project may interest teams exploring inventory and warehouse-management processes or building software for specific operations. Rather than imposing a generic process, adaptation starts by listening to the team, mapping its operations and prioritising where digital tools can deliver tangible value.

## Technology serving the people who run the warehouse

Useful innovation is not about accumulating screens; it is about reducing real friction. With clearly defined needs, this project can serve as a foundation for prototyping, validation and the evolution of a tool aligned with day-to-day operations.
